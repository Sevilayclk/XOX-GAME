# 🎮 XOX Game (Tic Tac Toe)

A simple command-line **Tic Tac Toe (XOX)** game built in Python.  
It features colorful symbols, automatic screen refresh, and a computer opponent!

---

## 🧩 Features
- Colorful X and O display using **Colorama**
- Automatic screen clearing after each turn (for a cleaner terminal look)
- Human vs Computer gameplay
- Win, lose, or tie detection
- Simple and easy-to-understand code structure

---

## 🕹️ How to Play
1. Run the Python file in your terminal.
2. The game board is numbered from **1 to 9** as follows:

```
 1 │ 2 │ 3
───┼───┼───
 4 │ 5 │ 6
───┼───┼───
 7 │ 8 │ 9
```

3. On your turn, type a number between **1–9** to place your mark (X).
4. The computer (O) will automatically make a move.
5. The game ends when someone wins or the board is full.

---

## 🧠 Game Logic
- Horizontal, vertical, and diagonal win checks  
- Randomized computer moves  
- Automatic player switching after every turn  

---

## 🧰 Requirements
Make sure you have **Python 3** installed, and then install the required library:

```bash
pip install colorama
```

---

## 🚀 Run the Game
To start playing, simply run:

```bash
python xox_game.py
```
